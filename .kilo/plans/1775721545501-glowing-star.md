# Plan: Fix Unresolved References in Spring Boot Kotlin on VS Code

## Goal
Resolve "unresolved reference" errors for Spring Boot imports (e.g., 'springframework', 'SpringBootApplication', 'runApplication') in the Kotlin backend, allowing VS Code to recognize dependencies and eliminate errors.

## Current Understanding
- Backend: Kotlin Spring Boot app with imports failing resolution in VS Code.
- Errors: "Unresolved reference 'springframework'", "Unresolved reference 'SpringBootApplication'", "Redeclaration: class Main : Any", "Unresolved reference 'runApplication'".
- App works: Builds and runs via Gradle, but VS Code IDE shows errors.
- Cause: VS Code not properly syncing with Gradle project or missing extension setup.

## Potential Issues
1. **Gradle Sync Missing**: VS Code hasn't imported the Gradle project, so dependencies aren't resolved.
2. **Extension Configuration**: Kotlin/Java extension not configured for Spring Boot.
3. **JDK Missing/Incorrect**: Wrong Java version or path.
4. **Workspace Settings**: VS Code workspace not set up for multi-module project.
5. **Cache Issues**: Stale IDE cache preventing dependency resolution.

## Investigation Steps
1. **Verify VS Code Setup**:
   - Confirm Kotlin and Java extensions are installed and enabled.
   - Check if Gradle project is imported in VS Code (look for .project files or Gradle views).

2. **Check JDK and Kotlin Versions**:
   - Ensure JDK 21 is installed and configured in VS Code settings.
   - Verify Kotlin version in build.gradle.kts matches extension support.

3. **Inspect Project Structure**:
   - Confirm backend folder has proper Gradle structure.
   - Check for .vscode settings or workspace config.

4. **Run Diagnostics**:
   - Attempt Gradle sync/reload in VS Code.
   - Check VS Code output for extension errors.

## Resolution Steps
1. **Sync Gradle Project**:
   - Reload VS Code window or re-import Gradle project.
   - Use VS Code command: "Java: Reload Projects" or "Kotlin: Reload Projects".

2. **Configure Extensions**:
   - Set Java home in VS Code settings to JDK 21 path.
   - Enable Kotlin support for Spring Boot in extension settings.

3. **Clear Caches**:
   - Delete .gradle caches and VS Code workspace cache.
   - Restart VS Code and re-open project.

4. **Verify**:
   - Check if errors disappear after sync.
   - Run Gradle build to confirm no issues.

## Risks
- Re-syncing might take time or require reinstalling extensions.
- Incorrect JDK version could cause compatibility issues.

## Dependencies
- VS Code extensions: Extension Pack for Java, Kotlin.
- JDK 21 installed and configured.
- Gradle wrapper in backend folder.</content>
