# Plan: Resolve Unreferenced Errors in Spring Boot on VS Code

## Goal
Understand and fix "unreferenced errors" in the Spring Boot backend project that appear in VS Code despite the application running correctly. These are likely IDE warnings about unused imports, variables, or dependencies.

## Current Understanding
- Backend: Kotlin Spring Boot app with basic structure (Main.kt, HelloController.kt, build.gradle.kts).
- Frontend: Next.js with TypeScript.
- Errors: IDE warnings (not build failures) about unreferenced elements.
- App works: Functional despite warnings.

## Potential Issues
1. **Unused Imports**: Kotlin compiler/IDE flags imports not used in code.
2. **Unused Variables/Functions**: In controllers or services.
3. **Unused Dependencies**: In build.gradle.kts (e.g., PostgreSQL runtime-only).
4. **VS Code Settings**: Java/Kotlin extension configurations causing false positives.
5. **Strict Mode**: Compiler flags treating warnings as errors.

## Investigation Steps
1. **Examine Codebase**:
   - Read all Kotlin files to identify unused imports/variables.
   - Check build.gradle.kts for unused dependencies.
   - Search for patterns of unused elements using grep.

2. **Check VS Code Configuration**:
   - Inspect Java/Kotlin extension settings.
   - Look for custom linting rules or error reporting.

3. **Run Diagnostics**:
   - Attempt to run Gradle build to capture warnings (if allowed).
   - Check for Kotlin compiler warnings.

## Resolution Steps
1. **Remove Unused Code**:
   - Delete unused imports and variables if not needed.
   - Comment or suppress warnings for placeholders.

2. **Adjust Dependencies**:
   - Remove or move unused deps to test scope if appropriate.

3. **Configure VS Code**:
   - Disable strict warnings or adjust extension settings.
   - Add annotations to suppress warnings.

4. **Verify**:
   - Ensure app still builds and runs.
   - Run linting to confirm errors resolved.

## Risks
- Removing code might break future features if placeholders.
- Suppressing warnings hides potential issues.

## Dependencies
- Kotlin/Java extension in VS Code.
